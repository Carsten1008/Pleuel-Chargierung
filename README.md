# Chargieren von Schiffsmotor-Pleueln – 3D-Animation

Interaktive 3D-Animation, die zeigt, wie Pleuel für die Wärmebehandlung auf ein Chargiergestell chargiert werden. Je vier Pleuel hängen, im großen Auge aufgefädelt, auf der Stange eines Elektro-Deichselstaplers („Ameise“) und werden gemeinsam in eine Führung des sternförmigen Gestells eingebracht (2 Ebenen × 6 Führungen × 4 Pleuel = 48 Pleuel).

**Animation ansehen:** https://carsten1008.github.io/Pleuel-Chargierung/

## Bedienung

- **Abspielen / Pause / Neu starten** über die Leiste am unteren Rand
- **Zeitleiste** zum Springen an eine beliebige Stelle
- **Tempo** 0,5× bis 4×
- **Ansicht drehen:** mit der Maus ziehen, **Zoomen:** Mausrad bzw. Zwei-Finger-Geste
- **Kamera dreht:** automatische Kamerafahrt ein/aus

Die ersten beiden Chargen laufen in Echtzeit, die weiteren im Zeitraffer (ca. 3×).

## Hinweise

- Schematische Darstellung. Gestell, Pleuel und Stapler sind vereinfacht nachgebildet, alle Maße sind angenommen.
- Die Seite lädt keine externen Ressourcen: three.js ist direkt in `index.html` eingebettet, es werden Systemschriften verwendet.
- **Offline-Start:** `index.html` herunterladen und doppelklicken, die Animation startet im Standardbrowser (Chrome, Edge, Firefox, Safari) automatisch.
